Assessment methodology v1
Five dimensions: security, revenue, services, sovereignty, accountability.
Design/potential and observed outcomes are separate arrays. Ordinal scale:
-2 strongly adverse; -1 adverse; 0 mixed/neutral; +1 beneficial; +2 strongly
beneficial. Null means insufficient evidence, never zero or failure.
Design scores require a readable agreement. Outcomes require a separate
implementation_report. Non-null scores require a verbatim excerpt matched to
the supplied document. Invalid references/quotes/roles suppress the score.
This verifies textual support, not truth, representativeness or causality.
Source reports can be contested; human review remains necessary.
At most 70,000 characters per document enter each AI request. Truncation is
recorded in input_documents. This is a provisional document assessment, not
exhaustive legal review. Underlying texts can contain missed context or OCR errors.
Model, prompt version, timestamps, input hashes and record fingerprint are saved.
Source changes mark assessments stale on worker restart and remove review status.

Signing-administration comparison
Dates group records under Mobutu, Laurent-Désiré Kabila, Joseph Kabila or Félix
Tshisekedi; unknown dates remain unverified. This is signing chronology only,
not causal credit for results, nor proof of who negotiated or implemented a deal.
In particular, later governments can implement agreements inherited from earlier
ones. No single overall government-strength score is generated.
The chart shows dimension means and n, excludes missing values, and defaults
to human-reviewed drafts. Optional provisional mode includes completed AI drafts.
Review means an analyst accepted a draft, not independent certification.
Evidence gaps and non-random document coverage prevent fair causal rankings.

Chronology correction discovered during pilot
The Sicomines evaluation was uploaded under a 2026 path, but title pages say
September 2021 and identify an interim ITIE-RDC consultancy report. It is now
implementation evidence for the 2008 collaboration convention, and historical
context ONLY for Amendment 5 (2024). The server refuses outcome scores unless
a dated implementation report postdates the agreement's recorded date.
Run scripts/link_agreement_evidence.py after re-import/OCR to restore these
explicit links. The original convention's 22 April 2008 date is corroborated
by Amendment 5's title, not inferred from the original scan filename.

Citation validation v2
Pilots showed that model-written quotations can be shortened or paraphrased.
agreements-v2-passages supplies numbered 900-character source passages and
requires document_id + passage_id. The server inserts the source passage itself
and verifies it against the supplied document; model-authored quotations are
not displayed as verified evidence. Score validation still checks document role
and chronology. Narrative interpretation remains a provisional AI draft.

Live validation
39 Rust tests plus agreement UI and map interaction tests pass. Source-passage
matching prevents fabricated quotations but cannot validate the reasoning. The
2008 Sicomines pilot was withheld after it misread a production quantity and
extended claims beyond selected passages. Its assessment is failed, unreviewed,
and excluded from charts. Do not treat AI drafts as verified historical findings.
Browser visual verification was unavailable because the Mac was locked.

Automatic discovery (18 October 2026)
The Rust worker now polls configured CongoMines, Ministry of Economy and APCSC
indexes on startup when due, then every six hours (AGREEMENTS_POLL_SECONDS,
minimum one hour). Checks persist in SQLite, so a restart does not reset the
schedule. POST /v1/agreements/discovery/refresh queues an early check; status is
included as discovery in GET /v1/agreements and shown in the dashboard.

Candidates are keyword-matched links, not confirmed signed agreements. They
retain source URL, publisher, discovery timestamp, file hash and original HTML
or PDF. Up to three linked PDFs are archived per candidate. PDFs need subsequent
text extraction/OCR and instrument verification before scoring. Discovered source
roles cannot support design or outcome scores automatically. Unknown dates and
signatories remain unknown. Queue URLs are unique; existing register URLs are
skipped. Up to ten documents per source per cycle are fetched, pending before
failed retries. Fetches respect existing robots, allowlisted redirects, size caps
and delays; errors remain visible. No paid AI requests occur during discovery.

Coverage is limited to links visible in these configured indexes. It is not a
comprehensive web search, peace-treaty feed or revision monitor. An existing
saved document is not silently replaced when a publisher changes it. Additional
peace registries and approved research connectors can be added later. Keep the
SQLite database and data/agreements archive when deploying.
